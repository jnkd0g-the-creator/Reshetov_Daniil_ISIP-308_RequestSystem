# Самостоятельная ручная приёмка студентом

Статус: **BLOCKED / ещё не выполнена студентом**.

Агент может воспроизвести действия Chromium/Playwright и проверить API/БД,
но не может честно утверждать, что студент лично выполнил ручной прогон.
`test_cases.csv` содержит отдельные фактические результаты автоматизированной
проверки и поле `manual_status=BLOCKED`.

Порядок завершения: открыть приложение по README, войти локальным тестовым
аккаунтом, повторить каждый UI-сценарий из CSV; API-сценарии проверить Swagger
или curl. Зафиксировать дату, браузер, фактический результат, PASS/FAIL/BLOCKED
и доказательство самостоятельно. Не включать пароль/сессию в снимок.
После этого обновить данный файл и собственные manual_status, не переписывая
исходные результаты агента. Проверить репозиторий/видео с правами преподавателя.
