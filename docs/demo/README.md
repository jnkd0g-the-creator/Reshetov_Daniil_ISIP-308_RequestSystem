# Демонстрация CoffeeDesk

`coffeedesk_rehearsal.mp4` — **техническая запись реального приложения,
API и фактического запуска pytest, без аудиодорожки**. Это репетиционный
материал агента, **не готовое обязательное видео студента** из ЛР10.
Не выдавайте его за запись с вашим голосовым комментарием.

Запись воспроизводится `python scripts/record_demo.py` на отдельной временной
SQLite, содержит только учебные данные. Вход выполнен API до начала записи
страницы: пароль, cookie и CSRF не показываются. Pytest запускается действительно
во время записи; локальный служебный экран только транслирует stdout процесса,
не подставляет заранее подготовленный результат. MP4 создаётся из реального
Playwright screencast через ffmpeg; metadata содержит длительность.

## Обязательная запись студентом (≤5 минут, с собственным голосом)

| Время | Действие и пример содержания комментария |
|---|---|
| 0:00–0:20 | Назвать ФИО, ИСИП-308, CoffeeDesk; «Система учитывает эксплуатационные заявки кофе-баров». |
| 0:20–1:00 | Открыть работающую систему, показать список, поиск, категории. Авторизоваться заранее, не показывать пароль. |
| 1:00–2:30 | Создать заявку на кран; изменить описание; назначить мастера; пройти статусы; перезагрузить и подтвердить сохранение. Объяснить различие прав ролей. |
| 2:30–3:15 | В Swagger/curl показать успешный GET и ошибку 404/422, не выводить вход/CSRF. |
| 3:15–4:30 | В терминале запустить `python scripts/run_tests.py`, дождаться результата. Объяснить assert HTTP 422 для BUG-01 и отдельную тестовую БД. |
| 4:30–5:00 | Назвать готовые функции и ограничения; внешний URL, если уже согласован, либо честно объяснить отсутствие удалённого стенда. |

Можно использовать OBS/запись экрана ОС. Презентация и скриншоты вместо действий
не подходят. Не копируйте синтетический голос под видом собственного.
Сохраните финальную запись MP4 или ссылку с доступом преподавателю; проверьте
в инкогнито. После фактической записи обновите статус ниже и итоговый отчёт.

**Финальное голосовое видео студента: BLOCKED / ещё не записано.**
Публичный пароль в Git не добавляется; преподавателю доступ выдаётся отдельно.
