# План и исходное состояние ЛР6

Ветка feature/lab6 создана от develop после ЛР5 (fc8aa44).
Уже готовы ТЗ, архитектура, прототип и SQL. Реализуются FR-01–13, FR-16;
публичный контракт FR-14 закрепляется в ЛР7, Docker FR-15 — в ЛР8.

1. DTO/config/security + SQLite unit of work и Repository.
2. Сервисы: роли, CRUD, назначение, состояния, история, комментарии, архив.
3. Реальные экраны поверх внутренних HTTP-контроллеров `/ui-api`.
4. Изолированный smoke-прогон, скриншоты, чистый запуск, README и отчёт.

Минимум три содержательных коммита, каждый публикуется. Слияние в develop после
проверки. БД на уровне соединения получает FK и CASEFOLD для кириллицы.
Пароли генерируются локально; учебный SQL-снимок не превращается в рабочую базу.

Ручная приёмка студентом не подменяется скриптом. Агент запишет инструментальные
результаты; полный ручной чек-лист с честным статусом будет в ЛР9.
