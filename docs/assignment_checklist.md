## Честность отчётности

Разработка и доступные инструментальные проверки выполняются ИИ-агентом
OpenCode, модель **GPT-6.1 Sol (`openai/gpt-6.1-sol`)**. Это не выдаётся за
самостоятельно выполненную студентом ручную работу. Сгенерированные результаты
проверяются реальным запуском. Формулируемые в ходе работы аналитические запросы
и ответы фиксируются как этапы одной текущей сессии, а не как выдуманные обращения
к другим моделям. Студенту необходимо самостоятельно просмотреть результаты,
повторить ручные сценарии и записать собственный голосовой комментарий.

Недоступные внешние действия отмечаются BLOCKED, а не PASS. Для удалённого
деплоя нужен согласованный сервер. Никакие пароли и токены не включаются в Git,
отчёты, скриншоты и видеоматериалы. Учебные имена пользователей вымышлены.

## Порядок Git

Каждый значимый этап: проверка → commit → push. ЛР 1–5 — main/develop;
ЛР 6–8 — отдельные feature/labN → develop; финальная версия — merge в main.
Исходный репозиторий уже создан, поэтому повторный `git init` не нужен.
Существующее `.venv` используется без пересоздания.
