# Прототип CoffeeDesk (ЛР4)

Открыть `index.html` в браузере, установка/сервер не нужны. Это самостоятельный
интерактивный HTML-прототип (разрешённый методичкой «другой инструмент»), не Figma
и не готовая программа. Данные вымышлены, формы не сохраняются в БД.

| Экран / hash | Назначение и действия | Роли |
|---|---|---|
| `#login` | Вход, обращение к администратору | Все |
| `#list` | Список, поиск, фильтры, создание, переход в карточку | По серверному scope роли в будущей реализации |
| `#new` | Тема, бар, категория, описание, приоритет; сохранить/отмена | Заявитель, оператор, admin |
| `#detail` | Реквизиты, история, комментарии, назначение, переход статуса | По матрице прав; пример показан для admin |
| `#edit` | Изменение реквизитов; сохранить/отмена | Оператор/admin, автор собственной новой |
| `#error`, `#empty` | Ошибка с сохранением ввода, пустой поиск со сбросом | Все |

Ролевая проверка в прототипе не реализована; её нельзя заменять скрытием кнопок
в реальном приложении. Пример архива специально подписан как пример диалога,
так как показанная карточка ещё в работе. В реализации архив появляется только
на закрытой заявке. Навигация: вход → список → создание → карточка → редактирование.

## UX-чек-лист и ревью

Проверить: понятный следующий шаг; текстовые статусы; подписи и ограничения;
ошибки рядом с формой; отмена без изменений; пустое состояние; фильтры совместно;
клавиатура/видимый фокус; узкий экран; явное подтверждение архива.

| Замечание ИИ-агента | Решение | Результат после доработки |
|---|---|---|
| Цвет не объясняет статус | Принято | Текст в каждом badge |
| Неизвестна допустимая длина | Принято | Подсказки 3–120, 10–4000, HTML-ограничения |
| Ошибка очищает всю форму | Принято как требование реализации | Отдельная область ошибки, не новая страница |
| Неясно, что делать при пустом поиске | Принято | Сброс фильтров и объяснение |
| Нужна мобильная навигация | Принято | Боковая панель становится верхней, ширина 390 px |
| Архив без подтверждения опасен | Принято | Диалог с номером и кнопкой отмены |
| Добавить фото и чат-бот | Отклонено | Не входят в утверждённый MVP |

Скриншоты `screens/*.png` получены Chromium/Playwright из этого файла;
генерация `.venv/bin/python scripts/capture_prototype.py`. Студенту следует
самостоятельно пройти сценарий и оценить удобство — автоскриншот этого не заменяет.
