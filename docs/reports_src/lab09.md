# 1. План и среда

Цель — проверить готовую версию CoffeeDesk после ЛР8, не добавляя крупные функции. Созданы testing/lab9/test_plan.md, набор кейсов, доказательства и реестр дефектов. Исходная версия — 9e9cb12; точный commit и SHA256 каждого прогона указаны в environment.json. Ubuntu 26.04, Python 3.10.11, Chromium 140/Playwright 1.55.0, SQLite 3.46.1, curl. Каждый запуск получает отдельный HTTP-порт и временную БД.

Проверены функциональные сценарии, негативные данные, границы, роли, UI/API → SQLite и HTTP-коды. Реальные пользователи и рабочая БД не затронуты. Не проверены внешняя сеть/DNS/TLS, промышленная нагрузка и самостоятельный ручной прогон студентом.

# 3. Найденные дефекты и retest

BUG-01, Medium: JSON cafe_id=true превращался в 1, API отвечал 201 вместо 422 и создавал лишнюю строку. Ошибка сначала сохранена коммитом 9763dbe, затем исправлена strict=True; повтор исходного запроса дал 422 и исходные 12 строк. Исходный FAIL не перезаписан: evidence/BUG-01_before_fix.*, отдельный retest рядом.

TEST-01, Low, тестовая инфраструктура: первый полный прогон дал 29 PASS / 1 FAIL. TC-02 проверял badge до окончания перехода, Playwright находил шесть badge списка. Приложение не менялось; тест стал ждать заголовок карточки, затем проверять прежний строгий assert. В initial_failure/ сохранены ошибка и исходные метрики. После исправления снова пройдены все 30, а не только TC-02.
