# 1. Цель и критические сценарии

Цель — автоматизировать ключевую регрессию, оценить качество и подготовить демонстрацию. После ЛР8 крупные функции не добавлялись: исправлен зарегистрированный дефект валидации и улучшено ожидание теста. Критические сценарии: создание/автор/аудит, сохранение изменений, поиск/фильтры, назначение/статусы, архив. Все они подходят для автоматизации, потому что имеют воспроизводимые входы и проверяемые результаты.

В testing/lab10/ размещены conftest.py, test_business.py, test_api.py, test_auth_config.py и инструкция. Используются pytest, FastAPI TestClient, SQLite в tmp_path и случайный тестовый пароль в памяти. Рабочие пользовательские данные не меняются. Набор включает существующие smoke и регрессию ЛР9: всего 57 параметризованных запусков, значительно больше минимума 10, со всеми требуемыми категориями.

# 2. Запуск и результат

Одна команда из корня после установки зависимостей: python scripts/run_tests.py. Она запускает весь набор, сохраняет полный stdout в testing/lab10/test_run.txt, JUnit, coverage JSON/XML и run_metadata.json с commit и хешем исходников. Фактический полный прогон: 57 PASS, 0 FAIL, 0 ошибок, 0 пропусков. Покрытие строк Python — 90,38%; это не покрытие UI/JS и не гарантия отсутствия ошибок. Депрекейшн-warning зависимости показан в логе, не скрыт.

Важное ограничение: аудиодорожки нет. Техническая репетиция агента не заменяет обязательное видео с голосом студента. План ≤5 минут, требования безопасности и порядок записи собственного видео — docs/demo/README.md. Голосовое видео, самостоятельный ручной прогон и согласованный внешний сервер остаются BLOCKED. ЛР10 нельзя объявить полностью сданной до их выполнения.

Модель GPT-6.1 Sol. Два полных подзапроса — черновики автотестов и анализ реального сбоя — docs/ai_log.md, ЛР10. Приняты tmp_path, строгие assert и ожидание конкретного heading; изменены предположения о JWT и импортах, отклонено ослабление локатора .first(). Проверка — реальные логи, а не вывод модели. Самостоятельная проверка студентом ещё требуется.

Вывод: программная часть готова к локальной демонстрации, регрессия проходит. Полная сдача ограничена тремя явно указанными внешними/личными действиями, которые не подменены вымышленным PASS.
