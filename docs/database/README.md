# База CoffeeDesk (ЛР5)

`schema.sql` создаёт 9 таблиц с нуля; `seed.sql` — 6 вымышленных пользователей,
3 бара, 5 категорий, 4 статуса, 12 заявок, 5 комментариев, 12 записей истории.
Повторное применение не стирает данные. Все FK включаются на каждом connection.
Ключи и обязательные поля явно перечислены в SQL. Нормализация до 3НФ в рамках
учебного анализа: названия ролей/баров/статусов/категорий не копируются в заявку;
комментарии и аудит выделены, номер `CB-xxxxx` вычисляется из PK, не хранится второй
копией. Даты создания/изменения относятся к заявке, не к справочникам.

Связи Roles 1:M Users; Users 1:M Requests (автор и мастер отдельно), Comments,
RequestHistory, Sessions; Cafes/Categories/Statuses 1:M Requests;
Requests 1:M Comments/RequestHistory. М:M для текущего MVP не требуется.
Бизнес-правила «мастер имеет роль technician» и порядок статусов проверяет сервис;
FK гарантирует только существование записи.

## Учебный снимок

`coffee_demo.sqlite3` намеренно хранится в Git по методичке. В нём нет рабочих
паролей: `password_hash='!unset'`, сессий нет. Рабочая база `data/coffeedesk.db`
исключена из Git. CLI инициализации в ЛР6 создаёт пароли локально.

## Упражнения SQL

`queries.sql` содержит 5 INSERT, 6 SELECT, 2 UPDATE, 2 DELETE, минимум 3 SELECT
с WHERE и минимум 2 с JOIN. Изменения выполняются в транзакции с ROLLBACK,
поэтому демонстрационный набор не портится. Физическое удаление применяется
только к временным учебным строкам, не к бизнес-операции архивации.

В черновике ИИ назначенный мастер соединялся `INNER JOIN Users assignee`;
исправлено на `LEFT JOIN`, иначе новые неназначенные заявки терялись.
Сравнение по реальным данным: результирующий запрос включает все 13 строк
(12 демонстрационных + 1 временная), включая NULL-исполнителей.

Запуск: `.venv/bin/python scripts/database_evidence.py`.
Проверены повторные schema/seed, integrity_check, foreign_key_check, отказ
несуществующего FK. Результаты: `query_results.txt/json`, `verification.txt/png`.
ER: `er.svg/png`; генерация `scripts/draw_diagrams.py er`.
Результаты получены агентом запуском SQLite, не выданы за ручную работу студента.
