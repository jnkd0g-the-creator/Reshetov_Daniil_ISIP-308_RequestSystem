# Ревью Dockerfile (ЛР8)

Первый вариант сохранён как Dockerfile.before и отдельным Git-коммитом.
Он был черновиком, не запускался как финальный образ. Ревью того же ИИ-агента:

| Замечание | До → после | Проверка |
|---|---|---|
| По умолчанию процесс root | Нет USER → USER 10001:10001 | docker inspect Config.User; id в контейнере |
| Каталог SQLite недоступен non-root | Нет подготовки → install -d owner coffee | init-db в томе от UID 10001 |
| Нет container healthcheck | Только HTTP endpoint → Docker HEALTHCHECK с DB | State.Health и curl /health |
| COPY всего проекта опасен | Уже узкий COPY src + два SQL | dockerignore исключает .env/.local/DB/report |
| Зависимости теряют кэш при правке кода | requirements до src сохранён | Последующая сборка использует кэш |
| Порт и база не фиксируются в коде | ENV PORT/DB, compose volume | Альтернативный порт 8001, перезапуск с томом |

Не добавляются ненужные компиляторы/curl в образ: healthcheck использует stdlib.
Базовый Python 3.10 выбран пользователем; ветка Python уже устаревающая для
долгосрочного production, учебный проект использует согласованную среду.
Перед реальным production следует согласовать поддерживаемый Python,
просканировать зависимости и закрепить digest базового образа.

Не утверждается проведение security-аудита, CVE-сканирования и удалённого деплоя,
если их фактических логов нет. Контейнер предназначен для учебных данных.
